# Лабораторна робота №3

Тема: Реалізація обробки виключень, модульності та документації в проектах Python.

Виконані завдання:

1. task1.py - обробка виключень за допомогою try, except, else, finally.
2. task2.py - створення власних виключень та їх ієрархії.
3. student_app - організація програми в модулі та пакети.
4. task4.py - документування коду, анотації типів та перевірка документації.

Запуск програм:

```text
python task1.py
python task2.py
python -m student_app
python task4.py
```

Для запуску потрібен Python 3.

У проєкті використано пакет student_app з підпакетами models та utils.

Програми використовують стандартні бібліотеки Python і не потребують встановлення додаткових залежностей.
